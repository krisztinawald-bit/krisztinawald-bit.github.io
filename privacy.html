Privacy policy

Last updated: October 23, 2026

Who uses this app

This Google OAuth app is used only by its owner, for personal automation. It is not available to the public.

What data it accesses

With the owner's permission, the app allows Make.com to access files and folders in the owner's own Google Drive account, as required by the automation scenarios the owner builds.

How the data is used

Data is used only to run the owner's own automations. It is not sold, shared with third parties for advertising, or used for any other purpose.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time in the Google Account settings under Security, Third-party apps with account access.
